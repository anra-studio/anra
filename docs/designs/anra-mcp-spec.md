# Anra MCP Spec

状态：设计草案。MCP 服务与本规范中的授权和窗口接口尚未实现。

Anra MCP 是核心提供的上下文服务，供已授权的外部执行端读取角色定义和某次交接
固定的 Tape 上下文。它独立于具体 integration plugin；plugin 负责建立外部执行，
不转发或替代执行端对该服务的调用。

关联文档：[Plugin Spec](plugin-spec.md) 定义接入机制；
[Plugin Integration Spec](plugin-integration-spec.md) 定义何时创建 anchor 和授权。

## 上下文模型

角色 Tape 保存 Anra runtime 的执行记录及经授权接入的外部观察记录。Context Window
是针对一次工作从 Tape 选择和投影出的模型输入，不等同于整条 Tape。交接 custom
anchor 在外部工作提交前固定角色版本及窗口引用，结构见
[Plugin Integration Spec](plugin-integration-spec.md#交接-custom-anchor)。

新消息、其他工作和后台观察记录不会扩大已固定窗口。服务按 anchor 重建或读取该
窗口；无法重建时返回明确错误，不能改读最新 Tape。窗口应保留来源与会话边界，
以及请求、工具调用和结果之间的必要关系。anchor ID 是引用，不是凭据。

现有 `anra.dev/anchor/v1` 仅识别初始化与 agent turn 记录，解码器拒绝未知类型。
交接 anchor 使用 `anra.dev/anchor/intr/v1`，现有解码器需要支持 schema 分派；
Tape `Source` 表示 Tape 身份，不应直接当作应用来源。具体存储和投影格式待核验
tape-go 的能力后冻结。

## 只读能力

首版需要以下 MCP 工具。工具名、JSON schema 和传输配置在实现设计阶段冻结；以下
是必须满足的语义，不是已经可调用的 API。

| 能力 | 请求 | 成功结果 |
| --- | --- | --- |
| 读取角色 | 已授权的交接 anchor 引用 | 本次工作固定的 Role 身份与定义版本 |
| 读取窗口 | anchor 引用、可选的分页游标和页面大小 | 同一快照内的窗口内容、来源、范围、完整性及后续游标 |

分页游标必须绑定原窗口、授权范围和投影版本；重复读取应得到同一内容，不能因
Tape 增长改变结果。页面大小、输出大小应有上限；空窗口与不存在的窗口可区分。
超出上限不能静默截断并标为完整。未知或不支持的 entry 类型应明确表达，不能
忽略依赖或当作已完整返回。

## 授权与连接

请求身份由受控 MCP 连接认证；授权绑定 Role、交接 anchor、目标应用绑定、允许操作、
Tape 快照/范围及有效期。服务按已验证的调用身份核验授权，不从工具参数中的
角色名、session ID 或 anchor ID 推断身份。跨角色、跨绑定、过期和撤销的访问拒绝。
连接凭据通过受控配置交付，不放入 prompt、entry 或 artifact。

外部 session ID 尚未产生时，授权可先绑定目标应用与交接 anchor；取得可验证的外部
关联后再登记。session ID 由调用者填写本身不证明身份。不能假定某个应用支持
会话级凭据注入；实际身份、部署和撤销方式需要接入验证。

调用者无法建立满足上述约束的授权连接时，交接不得假装上下文已经可用。
缺少身份、无权读取、授权过期/撤销、引用无效、窗口不可重建和暂时不可用应当
可以区分，同时不向未授权调用者泄露其他角色或窗口的内容。

## 并发与生命周期

读取只访问已持久化、被授权的固定快照，不取得角色 reasoning admission。
角色可以继续处理其他消息；读取不能暴露未提交记录或改变窗口。服务不承担外部
session 的启动、状态观察、取消或结果写入。

一个关键待验证点是：调用发生在 Anra 当前 turn 仍在运行时，哪些记录已
持久化且可安全纳入固定窗口。现有已完成 turn 的 TapeView 不能自动证明
运行中上下文可安全导出。实现前须定义一致的快照边界，并验证其与原生写入、
后台观察写入和崩溃恢复的关系。

## 验收

通过 `tests/e2e/features/*.feature`、公开 API、真实 HTTP/MCP transport、临时磁盘
及确定性 fixture 验证角色版本、固定窗口、分页和重复读取；同时覆盖并发写入、
空窗口、无效游标、跨角色拒绝、授权过期/撤销、不可重建和服务重启。
读取在角色忙碌时仍可进行，且不扩大范围。开发运行 `mise run e2e`，交付运行
`mise run test`。
